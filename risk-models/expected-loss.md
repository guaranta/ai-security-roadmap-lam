# Expected Loss Model

## Fórmula básica

```
Risco = P(incidente) × Impacto × Exposição
```

| Variável | Significado |
|----------|-------------|
| **P** | Probabilidade de ocorrência no período |
| **I** | Impacto financeiro/operacional por evento |
| **E** | Fator de exposição (autonomia do agente, superfície de ataque) |

## Estratégias de resposta

| Estratégia | Quando usar |
|------------|-------------|
| **Aceitar** | Custo de mitigação > perda esperada |
| **Evitar** | Desabilitar funcionalidade de alto risco |
| **Reduzir** | Guardrails, segmentação, revisão humana |
| **Transferir** | Seguro cibernético, SLA com fornecedor |
| **Hedge** | Redundância, failover, backups imutáveis |
